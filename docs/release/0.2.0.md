# Pace 0.2.0

发布日期：2026-10-07

这个版本内置 Pi 1.0.4，并修复了已登录的 provider 在 token 过期后无法继续使用的问题。按 [版本号规则](macos.md#怎么选版本号)，内置 Pi 升级带来新能力、Azure provider 改名属于配置变更，因此提升 minor。

## 升级须知

- **Azure 用户需要改名**：Pi 1.0.3 把 Azure provider 从 `azure-openai-responses` 改名为 `azure`。请把 `~/.pi/agent/auth.json`、`models.json` 和 `settings.json`（`defaultProvider`、`enabledModels`、`modelThinkingLevels`）里的旧名改成 `azure`，或在 Settings → Providers 重新填写 Azure 凭据。用旧 provider 的会话恢复时会换到其他模型，提示缓存不会复用。`AZURE_OPENAI_*` 环境变量不变。

## 新功能

- 内置 Pi 1.0.4（原为 0.99.1）：codemode 的提示 token 减少约 40%，出错时会告诉模型怎么恢复。脚本可以用 `models.generateImages()` 生成图片，每张图片同时写入临时文件；`tools.read()` 读取图片文件时返回图片。
- Azure Foundry 聊天模型：`azure` provider 也支持 Foundry Chat Completions 部署，首个是 `azure/deepseek-v4-pro`。

## 改进

- MCP 按服务器分别登录：MCP 的 OAuth 凭据改为按服务器名和 URL 存储，同一个 URL 的两个服务器可以用不同账号。已有的登录会自动迁到第一个使用它的服务器，Settings → MCP 显示的登录状态也随之更新。
- codemode 暴露方式合并：`codemode` 现在通过 `searchTools()` 查找服务器的工具，单独的 `codemode-deferred` 选项已移除；已设为 `codemode-deferred` 的服务器按 `codemode` 继续工作。

## 修复

- OAuth token 过期后无法刷新：安装版在 Radius、ChatGPT、GitHub Copilot、Kimi 等 OAuth 登录的 token 过期后，会报 “Provider authentication failed”，实际原因是打包产物里缺少 Pi 的刷新模块（`Cannot find module …/radius.js`）。现在打包时只保留一份 Pi SDK，token 过期后会自动刷新，构建也会检查这一点，防止再次回归。

## 已知限制

- 在聊天里输入 `/mcp login` 仍无法登录，请改用 Settings → MCP 的 **Sign in**。
- 会话启动时的 MCP 连接问题暂不会在会话内提示，需到 Settings → MCP 查看（[#416](https://github.com/BubblePtr/pace/issues/416)）。

## 安装与升级

- macOS：支持 Apple Silicon Mac，要求 macOS 12 或更高版本。首次安装请下载 `Pace-0.2.0-arm64.dmg`。
- Linux：支持 x64。推荐下载 `Pace-0.2.0-x64.AppImage`，加上可执行权限后运行；Debian / Ubuntu 也可以安装 `Pace-0.2.0-x64.deb`。详见 [Linux 打包与发布](linux.md)。
- 已安装用户（macOS 与 Linux AppImage）可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
