# Pace 0.2.1

发布日期：2026-10-07

这是 0.2.0 的修复版本，只包含修复，按 [版本号规则](macos.md#怎么选版本号) 提升 patch。

## 修复

- 发消息后窗口崩溃：0.2.0 在首页发消息，或在回复流式输出时打字，整个窗口可能变成 “Something went wrong”（React error #185，更新深度超限）。原因是 Pi 1.0 的事件流更密，而渲染层每收到一条事件都会额外触发更新：正在查看的会话在渲染后再回写“已读”，步骤标签和文本组件也会在每次渲染时重复更新状态，React 连续嵌套更新的计数因此超过上限。现在正在查看的会话在事件到达时就直接记为已读，这些组件也不再每次渲染都更新状态，每条事件只提交一次。内置的 Astryx `Text` / `Heading` 通过补丁修正了同类问题（上游已在 0.6.x 修复）。
- 模型选择器飞出层不关闭：指针从某一行移到底部的 **Add Models** 时，上一行不再保持高亮，选项飞出层会正常收起（[#442](https://github.com/BubblePtr/pace/issues/442)）。

## 已知限制

- 在聊天里输入 `/mcp login` 仍无法登录，请改用 Settings → MCP 的 **Sign in**。
- 会话启动时的 MCP 连接问题暂不会在会话内提示，需到 Settings → MCP 查看（[#416](https://github.com/BubblePtr/pace/issues/416)）。

## 安装与升级

- macOS：支持 Apple Silicon Mac，要求 macOS 12 或更高版本。首次安装请下载 `Pace-0.2.1-arm64.dmg`。
- Linux：支持 x64。推荐下载 `Pace-0.2.1-x64.AppImage`，加上可执行权限后运行；Debian / Ubuntu 也可以安装 `Pace-0.2.1-x64.deb`。详见 [Linux 打包与发布](linux.md)。
- 已安装用户（macOS 与 Linux AppImage）可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。如果 0.2.0 一发消息就崩溃，可以先在 Settings 里检查更新，不需要发消息。
