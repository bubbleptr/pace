# Pace 0.3.0

发布日期：2026-10-10

本版新增内置浏览器的页面评论，属于用户可感知的新功能，按 [版本号规则](macos.md#怎么选版本号) 提升 minor。没有数据或配置迁移，直接升级即可。

## 新功能

- 浏览器评论：在 Browser 面板打开 **Annotate**（`Cmd/Ctrl+Shift+A`），点击页面元素就能写评论。`Enter` 保存并继续标注，`Shift+Enter` 换行，`Cmd/Ctrl+Enter` 保存并立即发送。每条评论以芯片形式出现在 composer 的 **Browser comments** 分组里，发送时排在你的消息之后，并附上只截取被标注部分的截图；移除芯片即删除评论。点已保存的元素或编号徽章可以修改或删除。
- 区域框选：标注模式下按住拖动，可以评论页面上的一块区域，而不只是单个元素。截图围绕该区域裁剪，发给 Pi 的文字会说明区域在截图里和页面里的位置。

## 改进

- 刷新后评论还在：评论归属 Session，不随页面丢失。刷新或回到同一 URL 时标记会回到原位；原元素找不到时评论标为 stale（芯片显示为黄色），仍可连同保存时的截图一起发送。关闭窗口或退出应用后评论清空，不落盘。

## 已知限制

- 每个 Session 最多保存 200 条浏览器评论；每条评论各带一张截图，评论多时会占用较多上下文。
- 在聊天里输入 `/mcp login` 仍无法登录，请改用 Settings → MCP 的 **Sign in**。
- 会话启动时的 MCP 连接问题暂不会在会话内提示，需到 Settings → MCP 查看（[#416](https://github.com/BubblePtr/pace/issues/416)）。

## 安装与升级

- macOS：支持 Apple Silicon Mac，要求 macOS 12 或更高版本。首次安装请下载 `Pace-0.3.0-arm64.dmg`。
- Linux：支持 x64。推荐下载 `Pace-0.3.0-x64.AppImage`，加上可执行权限后运行；Debian / Ubuntu 也可以安装 `Pace-0.3.0-x64.deb`。详见 [Linux 打包与发布](linux.md)。
- 已安装用户（macOS 与 Linux AppImage）可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
