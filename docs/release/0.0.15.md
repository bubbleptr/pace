# Pace 0.0.15

发布日期：2026-09-23

## 新功能

- 检查 provider 连接：Settings → Providers 里每张已配置的卡片都有 **Check** 按钮，发一个 1 token 的请求，只显示一条状态：Working / Sign-in expired / API key rejected / Not covered by your plan / Can't reach provider / Check failed。订阅登录过期时给出 **Sign in again**，provider 原始报错收在 **Details** 里。
- 在设置页刷新模型目录：Settings → Models 每次进入时从 pi.dev 刷新一次目录，**Refresh models** 可强制刷新。上游新模型不必等 Pace 发版就能出现，已打开的会话无需重启即可看到；页面显示上次刷新时间和各 provider 的错误。
- 按 provider 全选：Models 页每张 provider 卡片加了 **Select all** 勾选框，一键勾选或清空该 provider 的全部模型，部分勾选时显示半选状态。

## 改进

- 只列出账号能用的模型：ChatGPT 订阅按账号实际可用的模型列出，包括 Pi 目录里还没有的新模型，并去掉已下线的模型（如 `gpt-5.3-codex-spark`）；OpenAI 和 Anthropic API key 只列出该 key 能访问的目录模型。账号列表拉取失败时回退到 Pi 目录。
- 模型选择器标注渠道：同一模型由多个 provider 提供时（如 ChatGPT 订阅和 OpenAI API key），每一行注明渠道，不再像是重复项。
- 新登录同步到已打开的会话：在设置页登录 provider 或添加 API key 后，已打开会话的模型列表会立即更新，不再只对新会话生效。
- 套餐错误说清楚：模型不在订阅套餐内导致运行失败时，聊天里直接说明原因并指向 Settings → Providers，不再只显示 Run failed。
- 内置 Pi 升级到 0.87.1：新增 Claude Opus 5.5、GPT-6 Sol / Luna，xAI 默认模型改为 Grok 4.7，支持按模型配置图片输入上限，并修复 Claude Fable 5.1 拒绝生成 compaction 摘要的问题。

## 修复

- 模型选择器与设置页不一致：Live 会话里的选择器排序和设置页不同，刚在设置页隐藏的模型要切换页面后才消失。现在两边排序一致，保存后立即生效。清空全部模型后会全部隐藏，不再悄悄恢复成显示全部。
  - 注意：旧版本里曾把所有模型取消勾选的用户，升级后选择器会是空的，需要到 Settings → Models 重新勾选。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.15-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
