# Pace 0.0.14

发布日期：2026-09-20

## 新功能

- 会话内显示上下文变更通知：Pi 在会话中途增删工具或更新 prompt 分区时，对话里出现一条居中的短通知（如 `Tools changed: +write, −bash`），不再被静默丢弃。Trajectory 视图也不再把这些条目当成 assistant 回合显示。
- Settings → About & Updates 显示内置 Pi SDK 版本，和 Pace 版本并列，方便反馈问题时同时说明两者。
- 首页 Pi 品牌色：空屏标题用 Pi 三色扫光，draft composer 聚焦和发送时显示同色描边，模型选择器显示 provider 图标。其余保持黑白；开启减少动态效果时为静态渐变。

## 改进

- Draft→Live 交接读起来像同一个 composer：宽度统一 44rem；footer 改为两态一致的 Location 行（Project folder / Git worktree、分支、用量环）；分支 chip 在会话创建期沿用 draft 的值；Project 选择器移到 hero 标题下方随标题淡出。
- 内置 Pi 升级到 0.86.0：带来 prompt cache 保温、按模型的 compaction 预算、离线 Radius 模型目录，以及一批 provider 修复（Copilot GPT 模型、DeepSeek、Gemini thinking 等级、Bedrock 缓存计价、OpenRouter 会话头）。

## 修复

- 从 Finder 启动的 Pace 安装、更新或移除 npm / git Pi 包时报 `spawn npm ENOENT`。现在会在常见安装位置查找 npm、pnpm 或 bun，并在本次操作内把其目录前置到 PATH；Pi settings 里显式配置的 `npmCommand` 仍优先。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.14-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
