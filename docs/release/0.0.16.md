# Pace 0.0.16

发布日期：2026-09-26

## 新功能

- 输入技能与提示模板：在输入框键入 `/`，或通过 `+` 菜单选择 Pi 当前可用的技能与提示模板。选中后显示为行内标签，恢复草稿时也会还原开头的命令标签。
- 引用工作区文件：在项目输入框键入 `@`，或选择 `+ → Reference file`，搜索项目目录或当前会话执行目录中的文件与目录。标签显示简短名称，发送时保留完整相对路径。
- 选择新 worktree 的基础分支：创建会话前，可在草稿的 Location 栏为新 worktree 选择基础分支；Git 信息尚未加载完成时作出的选择也会保留。
- 复制诊断信息：Settings → About & Updates 新增 **Copy diagnostics**，方便在反馈问题时附上应用、运行时与系统信息。

## 改进

- 命令与文件标签更清晰：发送后的消息也会显示技能、提示模板和文件引用标签；标签与正文对齐，菜单图标尺寸统一，长名称、说明和路径不会再把补全菜单撑出输入框宽度。
- 项目与分支状态更明确：目录已不存在的项目在侧栏变淡，启动会话时说明缺失的目录。草稿没有当前分支时显示 **No branch**。

## 修复

- 自动命名使用原始输入：会话标题根据用户实际输入生成，避免被技能或提示模板展开后的大段内容带偏。
- Provider 检查更可靠：优先用 provider 的默认模型检查连接；OAuth 凭据过期时提供重新登录入口，刷新凭据时的网络失败按连接问题提示。
- 模型列表保持同步：模型目录变化后，设置页和已打开的选择器一起刷新；多个刷新请求不再互相取消。
- 会话恢复与历史重试：重新连接时保留当前已活跃的会话，查看已归档会话不会重新订阅它；历史加载失败后重试，避免重复发起已失败的读取。

## 安装与升级

- 支持 Apple Silicon Mac，要求 macOS 12 或更高版本。
- 首次安装请下载 `Pace-0.0.16-arm64.dmg`。
- 已安装用户可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
