# Pace 0.1.0

发布日期：2026-10-01

从这个版本起，Pace 按语义化版本发版：有新功能或不兼容变更时提升 minor，只有修复时提升 patch。此前的 0.0.x 一律只升 patch，0.1.0 是第一个按新规则选出的版本号（规则见 [macOS 签名与发布](macos.md#怎么选版本号)）。

## 新功能

- MCP 设置：Settings 新增 **MCP** 分区，管理 Pi 全局 `mcp.json` 里的 MCP 服务器。可以查看每个服务器的连接状态（Connected / Needs sign-in / Failed / Disabled）和工具列表，启用或禁用、切换 exposure，通过浏览器完成 OAuth 登录与登出，添加 stdio 或 HTTP 服务器，以及删除服务器。配置改动对新会话生效；登录后，运行中的会话在下一轮就会用上新凭据。
- 内置 Pi 0.99.1：会话加载 Pi 自带的 codemode、tool_search 与 MCP 扩展，模型可以用脚本串联工具调用，按需搜索工具，并调用 MCP 服务器提供的工具。
- 嵌套工具调用：codemode 等工具在内部发起的工具调用显示在父调用下方。收起后显示 “N nested calls”，运行中显示 `Running codemode › server/tool…`，失败的嵌套调用会冒到父调用上；Trajectory 的检查器也会列出这些调用。MCP 工具名显示为 `server/tool`。
- Linux x64：每个版本同时发布 AppImage 与 deb。AppImage 支持应用内更新，deb 需要重新安装新版本。Linux 上使用系统窗口标题栏。
- 每次编辑的行数：工具步骤行显示整批编辑的合计 `+N -M`，展开后每次编辑各自显示增删行数。
- 打开聊天里的任意文件：聊天回答中的文件链接即使指向未修改的文件，也会在 Files 面板打开并定位到对应行。本地文件链接显示为带图标的文件标签；回答里以行内代码写出、且确实存在于工作区的路径（如 `src/foo.ts:12`）也可以点击。

## 改进

- 连续曲率圆角：界面圆角统一改为 squircle 形状，并调整圆角刻度，使整体圆润程度与之前一致；圆形按钮保持正圆。
- 动态图标更克制：所有动态图标的动画时长统一为 800ms，只在鼠标真正移入时播放，切换页面后不再自动重播，按下时不再缩放。

## 修复

- 聊天里的文件链接：指向未修改文件的链接点击后不再毫无反应。
- 会话记录体积：Pi 0.99 的 bash 结果附带的完整输出（最多 1 MiB）不再写入会话日志或进程间消息。

## 已知限制

- 在聊天里输入 `/mcp login` 仍无法登录，请改用 Settings → MCP 的 **Sign in**。
- 会话启动时的 MCP 连接问题暂不会在会话内提示，需到 Settings → MCP 查看（[#416](https://github.com/BubblePtr/pace/issues/416)）。

## 安装与升级

- macOS：支持 Apple Silicon Mac，要求 macOS 12 或更高版本。首次安装请下载 `Pace-0.1.0-arm64.dmg`。
- Linux：支持 x64。推荐下载 `Pace-0.1.0-x64.AppImage`，加上可执行权限后运行；Debian / Ubuntu 也可以安装 `Pace-0.1.0-x64.deb`。详见 [Linux 打包与发布](linux.md)。
- 已安装用户（macOS 与 Linux AppImage）可在 Settings → About & Updates 点击 **Check for updates**；下载完成后点击 **Restart to update**。
